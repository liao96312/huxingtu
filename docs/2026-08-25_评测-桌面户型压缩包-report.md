## Findings

### F-01：当前不是“精度稍低”，而是通用解析入口尚未完成

- `status`: validated
- `impact`: 现有 `fp-001` 成果不能外推为任意户型图准确率；对本包宣称房间或门窗F1会失真。
- `remediation`: 优先复用既有墙矩形/缺口/门弧/窗线聚类规则，实现通用 `image → wall graph → room polygons` 适配层；在此之前只报告 `notEvaluated`。

### F-02：1200px门槛过于保守，但不能靠直接放大绕过

- `status`: validated
- `impact`: 9张视觉清楚的约800px样本全部进入人工复核，自动覆盖率为0。
- `remediation`: 建立低清独立切片，用墙线连续性、OCR尺寸一致性和开口可辨识度取代单一短边阈值；只有独立测试过门后才降低阈值。

### F-03：裸Hough门弧提议不可用

- `status`: validated
- `impact`: 28～56个提议远高于肉眼可见门数，假阳性会封错墙或创建错误房间邻接。
- `remediation`: 保持既定顺序：墙带/墙图 → 候选弧 → 最近WallEdge → 两侧Room采样 → 置信门；不为本包新创独立门检测器。
