## Findings

### F-01：当前不是“精度稍低”，而是通用解析入口尚未完成

- `status`: validated
- `impact`: 现有 `fp-001` 成果不能外推为任意户型图准确率；对本包宣称房间或门窗F1会失真。
- `remediation`: 优先复用既有墙矩形/缺口/门弧/窗线聚类规则，实现通用 `image → wall graph → room polygons` 适配层；在此之前只报告 `notEvaluated`。

### F-02：1200px门槛过于保守，但不能靠直接放大绕过

- `status`: validated
- `impact`: 9张视觉清楚的约800px样本全部进入人工复核，自动覆盖率为0。
- `remediation`: 建立低清独立切片，用墙线连续性、OCR尺寸一致性和开口可辨识度取代单一短边阈值；只有独立测试过门后才降低阈值。

### F-03：墙掩膜能改善门弧提议，但仍未达到发布门槛

- `status`: validated
- `impact`: 留测F1 0.651，仍有11个FP和4个FN；若直接进入几何会封错墙或创建错误邻接。
- `remediation`: 新提议器只输出 `DoorArcProposal`；保持既定顺序：通用WallGraph → 最近WallEdge → 两侧Room采样 → 置信门，只有最终门洞F1达到0.90才能自动进入LayoutRevision。

### F-04：现成四类分割权重可改善墙约束，但不能直接识别本数据的门

- `status`: validated
- `evidence`: 隔离运行 `Yytsi/floorplan-to-3d@ccc1972` 与官方 `best.safetensors`（SHA-256 `d7f6a0fd...a8d6c`），CPU处理9张约6.5秒。
- `result`: 直接Door Mask留测Precision/Recall/F1为0.455/0.556/0.500；用其Wall Mask约束现有门弧提议后为0.609/0.778/0.683，优于形态学Wall Mask的0.651，但仍未过门。
- `impact`: 成熟模型适合替换墙掩膜基线，不适合直接写门；第8张仍有5个FP。
- `license`: 仓库和Hugging Face模型卡声明MIT，但权重训练于CC BY-NC 4.0 CubiCasa5K，商业来源链需单独确认。
- `remediation`: 只继续Wall Mask技术Spike；不复制第三方代码/权重进仓库，不把直接Door Mask接入生产。完整证据见 [`floorplan-to-3d-benchmark.v1.json`](./data/floorplan-to-3d-benchmark.v1.json)。

## Path

```text
9张PNG
  → 9/9解码成功
  → 9/9因短边<1200进入needsReview
  → 通用wall graph/room polygon入口缺失
  → 完整解析notEvaluated（0/9可执行）
  → 58个红框门真值
  → 前6张阈值选择 / 后3张留出测试
  → 墙掩膜门弧提议 test F1=0.651
  → 现成模型Wall Mask + 门弧提议 test F1=0.683
  → 未过0.90门，不进入LayoutRevision
```

当前红框足以评测门弧提议层；正式端到端准确率仍需要墙、房间和窗真值。人工标注不是生产流程必选步骤，而是计算Precision/Recall/F1不可缺少的评测基准。
